# Contador de Cliques em React

Este é um projeto simples desenvolvido em React para demonstrar o uso de componentes funcionais, gerenciamento de estado (state) e manipulação de eventos.

## 🎯 Objetivo
Criar uma aplicação que exibe um contador em tela. Cada vez que o botão "Clique aqui" for acionado, o valor do contador é incrementado em um.

## 🛠️ Tecnologias Utilizadas
- **React:** Biblioteca JavaScript para construção de interfaces.
- **useState:** Hook do React utilizado para gerenciar o estado do contador.
- **Create React App:** Ferramenta utilizada para configurar o ambiente do projeto.
